# 三分钟讲解

**问题**：A 还不了债，B 的入账减少，即使 B 没受到最初冲击也可能无法偿付 C。单家机构分析会遗漏资产负债网络反馈。

**做法**：有向债务矩阵加网络外债权人，按比例清偿，在有限责任与债务优先条件下求固定点。主算法逐步扩大违约集合，用有理数求解活跃子系统。

**演示**：A 外部资产减少 50%，A 直接违约，B/C/D 连锁违约。最终付款为 5,000、4,500、4,100、3,780 美元。全部债务未偿 12,020 美元，外部债权人短缺只有 3,380 美元，不能把内部重复暴露当成社会损失。

**验证**：逐机构检查付款边界与精确固定点残差，逐条核对债务流，再检查整个网络的资金勾稽。独立穷举违约集合算法对照全部演示和 100 个固定种子小网络。

追问要点：外部债务是容易验证的较强唯一性充分条件；Fraction 避免容差掩盖循环债务错误；算法轮数不是违约天数；同预算方案比较没有证明全局最优；独立 oracle 共享线性代数函数但使用不同系统构造与搜索路径，大型应用还应使用其他求解器复核。

简历可写“实现债务网络清算与交易对手传染分析，建立精确固定点证书、外部资金勾稽与独立违约集合穷举对照”。不要声称真实银行监管应用、最优注资或实际政策收益。
